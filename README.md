# Student Management System

A simple **Student Management System built using Python**. This project allows users to add, view, search, update, and delete student records.

## Features

* Add new students
* View all student records
* Search students using Student ID
* Update student information
* Delete student records
* Store student data permanently using JSON
* Menu-driven console interface

## Technologies Used

* Python
* JSON
* File Handling
* Functions
* Lists and Dictionaries
* Conditional Statements
* Loops

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run:

```bash
python main.py
```

5. Select an option from the menu.
